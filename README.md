# your-demo

- `index.html`: Team K (Harcourts Howick) demo site
- `thomas-consultants/`: 10 homepage redesign concepts for [thomasconsultants.co.nz](https://www.thomasconsultants.co.nz/)
  - `thomas-consultants/index.html`: review gallery where clients preview each concept (desktop/tablet/mobile), shortlist favourites, compare up to 3 side by side, and send their preferred design
  - `thomas-consultants/designs/NN-slug/`: the concepts, each a complete 6-page site (see `thomas-consultants/README.md`)
  - To receive selections directly, set `FORM_ENDPOINT` (e.g. a Formspree URL) or `SEND_TO` (email) at the top of the script in `thomas-consultants/index.html`. A share link (`?s=01,04&p=04`) also carries the shortlist and pick.
